One-line pickup line for an AI, entered in the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) bounty on make.fun.

## The line

> Are you backpropagation? Because every mistake I make with you just makes me love you more.

## How it works

`main.ts` composes the line from two parts — a question as the setup and an answer as the punch — validates it (one line, 1–200 characters, no extra whitespace), and writes it deterministically to `/output/entry.txt`. No input is read and no network is used, so the output is byte-identical on every run.

Run it with:

```sh
node main.ts
```
